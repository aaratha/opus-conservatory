327	### Client Bundle Warning (Vite-based frameworks)
328	
329	React Router, SvelteKit, Astro, and Nuxt all run on Vite. **Any module imported by a client component will be bundled to the browser.** `process.env` doesn't exist there.
330	
331	For publishable values (`projectId`, `dataset`, `apiVersion`, public studio URL), use the framework's client-safe env mechanism:
332	
333	- React Router / Remix: `import.meta.env.VITE_*`
334	- SvelteKit: `$env/static/public`
335	- Astro: `import.meta.env.PUBLIC_*`
336	- Nuxt: `useRuntimeConfig().public`

338	For secrets (read tokens, webhook secrets), read `process.env.*` (or the server equivalent) **only from server-only modules** — `.server.ts`, route handlers, API endpoints. Don't centralize them in a shared `env.ts` that anything else imports.

273	## 7. Safe Schema Updates (The Deprecation Pattern)
274	
275	**NEVER** delete a field that contains production data. It will cause data loss or Studio crashes. Instead, follow the **ReadOnly -> Hidden -> Deprecated** lifecycle.

277	### The Pattern
278	1.  **`deprecated`**: Adds a visual warning and reason.
279	2.  **`readOnly: true`**: Prevents new edits but keeps data visible.

281	4.  **`initialValue: undefined`**: Ensures new documents don't get this field.
282	
283	```typescript

286	  title: 'Article Title (Deprecated)',
287	  type: 'string',
288	  deprecated: {

290	  },
291	  readOnly: true,
292	  hidden: ({ value }) => value === undefined,
293	  initialValue: undefined
294	})
295	```
